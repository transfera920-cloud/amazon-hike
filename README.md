# 亞馬遜國家山岳協會 (Amazon Alpine Association)

## 專案簡介
亞馬遜國家山岳協會官方網站前台與後台管理系統。

## 前台顯示規範

**規範核心**：前台（非後台）任何頁面，都不得把「內部路徑、內部 ID、slug」當作可見文字顯示給訪客。

- **禁止顯示範例**：`/nav/btn_xxxx`、`/chapter01`、`/{categorySlug}/{activitySlug}`、按鈕 id、活動 id、slug 等。
- **涵蓋範圍**：適用於以後新增或維護的任何頁面、元件、卡片、標籤、麵包屑、頁尾或除錯資訊。
- **正常連結不受限**：正常的 `href`、`onClick`、`pushState` 等導覽行為不受限制，但不要把路徑字串直接印在畫面（JSX 文字節點）上。
- **後台不受限**：後台（`AdminPage.tsx`）可以顯示這些系統識別與路徑資料，以利管理者檢視與複製，不受此規範限制。
- **允許之內容資料**：內容資料不算內部路徑，可正常顯示：
  - 影片網址（如活動或花絮宣傳之 YouTube 連結）
  - 問卷編號（如 `#1`, `#2` 排序編號）
  - 更新日期（如專文更新日期）
  - 活動標題、描述、行程規劃及使用者在後台填寫之文字內容

### 實作檢查清單
之後每次新增或修改前台元件時，請主動搜尋確認是否含有把以下欄位直接渲染成可見文字的情況：
- `button.id`
- `activity.id`
- `activity.slug`
- `chapter.slug`
- `currentPath`
- `window.location.pathname`

若有，必須移除可見文字節點；這些欄位僅允許放進 `href`、`key`、DOM `id` 屬性、`onClick` 參數或 SEO meta 標籤中。
